## 2. 核心檔案設計與調整原則

### 2.1 一份 PDF，只證明一個核心觀點（第二層文件原則）
- **`P01`**：證明足球如何形成長期投入、面對失敗、壓力決策與輸球後回去加強再挑戰的人格模式。
- **`P02`**：證明「遇到真實足球問題（想分析球員近況） $\to$ 主動自學所需工具（Python爬蟲／pandas／AI）」。
- **`S01/S02/S04`**：分別證明系統實作能力、作品成熟度與失敗迭代修正。
- **`A01`**：證明「在足球、研究與競賽並行期間，仍維持穩定的校內學習表現，並從正式課程進一步拓展資訊能力、外部檢測與多元參與」。
  - **第1頁｜穩定的校內學習基礎**：四學期班排 3 $\to$ 3 $\to$ 5 $\to$ 3（皆維持前五）、數理及資訊代表成績；模考僅作小型佐證（高二階段：自然組班排1/34、校排10/325；社會組班排1/34、校排7/325，不放大總級分，不以模考為主敘事）。
  - **第2頁｜從課堂延伸到課外**：校內 Python 與 Arduino 課程、APCS 外部檢測、重要營隊、幹部團隊責任與少量具證明價值之未重複獎項（英文成績與檢定已在 L01 呈現，不在此重複展開）。
- **`L01`**：已確認歸屬第三層原始證明，內容為 GEPT 單科成績與英文競賽名次彙整，不列入第二層核心命題負擔。

### 2.2 明確區隔 A01 與 P02 的 Python 敘事
- **A01**：呈現校內 Python 與 Arduino 課程建立的正式學習基礎，以及 APCS 提供的外部標準檢測。
- **P02**：呈現當需要處理足球數據等更複雜的真實問題時，進一步自學爬蟲與資料處理能力的自主延伸歷程。
- **關係**：兩者為互補的「正式課程基礎」與「真實問題驅動自學」，不推定先後順序。
