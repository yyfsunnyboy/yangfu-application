## 2. 核心檔案設計與調整原則

### 2.1 一份 PDF，只證明一個核心觀點（第二層文件原則）
- **`P01`**：證明足球如何形成長期投入、面對失敗、壓力決策與輸球後回去加強再挑戰的人格模式。
- **`P02`**：證明「遇到真實足球問題（想分析球員近況） $\to$ 主動自學所需工具（Python爬蟲／pandas／AI）」。
- **`S01/S02/S04`**：分別證明系統實作能力、作品成熟度與失敗迭代修正。
- **`S03`**：第25屆旺宏科學獎（846件作品，全領域決賽20強，電腦資訊科學類4件進入決賽）；待決賽結果後更新，不得預寫獲獎。
- **`A01`**：呈現研究競賽、足球校隊與課業並行期間，仍維持穩定學業表現；並以 APCS 客觀檢視程式理解、實作能力及成長空間。
  - **學業數據**：四學期班排 3 $\to$ 3 $\to$ 5 $\to$ 3（四學期皆維持班級前五）；高二上第一次段考平均 78.56 (班排5/35, 年排40/339) $\to$ 第二次段考平均 84.44 (班排4/35, 年排19/339)，段考平均進步 78.56 $\to$ 84.44，年級排名進步 40 $\to$ 19。
  - **模考數據**：114學年度9月模考（自然組班排2/35、校排59/645、總級分45）；114學年度2月全國模考（自然組班排1/34、校排10/325、總級分48，數學A級分10 $\to$ 12）。模考母數不同，記載為「在不同母數的兩次模考中，第二次取得自然組 1／34、校排 10／325」。
- **`L01`**：GEPT中高級初試聽讀通過、複試口說通過與英文競賽名次彙整。
- **`T01`**：擺放於選繳資料最前面，核心主張為「文武不岐——我把球場上的紀律、合作與韌性，帶進課業與研究」，已完成，待最後照片與輸出確認。

### 2.2 明確區隔 A01 與 P02 的 Python 敘事
- **A01**：呈現校內 Python 與 Arduino 課程建立的正式學習基礎，以及 APCS 提供的外部標準檢測。
- **P02**：呈現當需要處理足球數據等更複雜的真實問題時，進一步自學爬蟲與資料處理能力的自主延伸歷程。
- **關係**：兩者為互補的「正式課程基礎」與「真實問題驅動自學」，不推定先後順序。
