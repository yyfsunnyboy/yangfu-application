## 0. 版本更新說明 (v0.1 → v0.2)

在 v0.1 中，我們建立了「成果不是目的，特質才是主角」的核心方向。  
在 **v0.2** 中，我們根據對《陽明交大百川學士學位學程特殊選才簡章》的重新對照，以及對陽甫成長軌跡的深化討論，進行了以下關鍵推進：

1. **對齊百川官方三層資料架構**：明確釐清第一層（官方必讀）、第二層（人物能力證據）與第三層（原始證明）的分工與定位。
2. **確立人物敘事主軸**：放棄「獎很多/AI很強/足球很強/全才」的表面標籤，聚焦於跨領域反覆出現的穩定行為模式：「遇到挑戰 → 嘗試 → 得到結果 → 發現不足 → 回去加強 → 修正方法 → 再挑戰」。
3. **更正程式能力形成時間線與 A01/P02 敘事區隔**：還原國三接觸程式、高一 C++ 基礎、因足球分析自學 Python、串聯 AI 至發現教育系統問題的真實時間軸。明確區隔 A01（校內 Python/Arduino 課程＋APCS 外部檢測）與 P02（真實足球問題驅動之爬蟲/資料處理自學）的互補關係。
4. **確立 A01 官方正式定位**：`A01｜校內學習與自主拓展`（2 頁分工：頁1「穩定的校內學習基礎」班排 3→3→5→3、數理資訊代表成績與模考小型佐證；頁2「從課堂延伸到課外」校內課程、APCS、營隊與幹部多元參與）。
5. **明確當前進度與後續順序**：能力佐證 PDF 已完成 6 份（P01、P02、S01、S02、S04、L01）；**目前只剩 A01 尚未完成**；A01 完成後，再製作 T01 成長軌跡總覽並進入整套編排。
6. **建構百川官方能力對照矩陣與待確認事項**。

### 1.1 第一層：官方必讀資料
- **手寫自傳**：近 5 年學習歷程與特殊表現（手寫 1000 字內）。功能不是堆成果，而是說明「我是誰」以及「如何形成現在的方向」。由於簡章限定近 5 年，幼兒園與國小經歷不能在自傳中大量展開，僅能作為背景源頭極簡提及。
- **學習計畫**：A4 三頁內。回答「為什麼選百川」以及「進入百川後想如何學習與發展」，必須與百川核心課程規定實質對接。

### 1.2 第二層：人物能力證據
- **歸屬欄位**：百川選繳「其他相關補充資料」。
- **核心原則**：「精簡且凸顯能力」、「一份 PDF，只證明一個核心觀點」。
- **包含文件**：`T01` 成長軌跡導覽、`P01` 足球、`P02` 足球×資料分析、`S01/S02/S04` AI系統與研究、`A01` 校內學習與自主拓展、`L01` 英文能力等。這層不是獎狀大全，而是經過嚴謹篩選的故事型能力證據。

### 1.3 第三層：原始證明
- **歸屬欄位**：百川選繳「其他有利的經歷證明文件」。
- **包含文件**：GEPT、APCS、各類證照、獎狀、參賽證明。若 `L01 英文能力` 主要為英檢證明，亦偏向此層。
- **整合策略**：校內、小型競賽與參賽證明，不需要每一件都獨立製作成故事型 PDF。應整理成一份精簡的「其他經歷／其他證明」合輯文件，保留完整紀錄而不稀釋主軸。

# 2. 目前最重要的敘事結論：人物核心定位

避免將陽甫包裝成「獎很多的人」、「AI 很強的人」、「足球很強的人」或「什麼都會的全才」。這些都不是最終的人物定位。

### 2.1 穩定的成長行為模式
陽甫真正吸引人且跨領域反覆出現的，是一個穩定的行為模式：

$$\text{遇到挑戰} \longrightarrow \text{嘗試} \longrightarrow \text{得到結果} \longrightarrow \text{發現不足} \longrightarrow \text{回去加強} \longrightarrow \text{修正方法} \longrightarrow \text{再挑戰}$$

### 2.2 足球場上形成的人格底色
這種行為模式最早、最長期地位於足球。足球對他的影響不只是運動成績，而是內化為：
- **面對失敗與更強的對手**
- **承受長期重複訓練**
- **高壓環境下的決策能力**
- **團隊合作與溝通**
- **輸球後的快速心理恢復**
- **回去加強不足，再次站上賽場挑戰**

### 2.3 核心敘事主軸
敘事主軸不是表面的「足球 $\to$ AI」，而是：

> **「足球場上形成的成長方式，後來出現在他的學習、程式、AI 與研究中。」**

另一個重要描述為：

> **「一次結果，不會決定他要不要繼續做；結果之後，他更在意下一步怎麼改進。」**

*註：以上為設計理念與故事底稿，後續撰寫自傳與學習計畫時，應轉化為具體事實而非直接喊口號。*

# 3. 程式能力形成過程：正確時間線與 Mentor 角色

在資料與故事中，必須還原真實的程式學習歷程，不能寫成從小天賦異稟。

### 3.1 正確時間線
1. **國中三年級**：才開始首次接觸寫程式，一開始是跟學長學習。
2. **高一初期**：參加一期免費的 C++ 基礎班，當時程式基礎其實仍然有限。
3. **動機萌芽**：因為喜歡足球且玩足球遊戲，想進行足球球員數據分析，發現既有基礎不足以處理需求。
4. **自主學習 Python**：為了抓住 FBref 資料，開始自學 Python、網路爬蟲、pandas 資料處理與數據分析。
5. **串聯 AI 與實作**：將程式能力進一步延伸至 AI 實作，完成後續競賽作品（如 S02 育秀盃）。
6. **探索更大問題**：發現 AI 與程式可以處理科展與更大的真實議題，主動詢問「科展可以做什麼？」。
7. **發現真實痛點**：父親提出一個日常生活觀察：「現在學生使用的學習網站很難用／不好用。」
8. **共同討論與迭代**：父子一起討論問題細節、研究可能方向，陽甫嘗試更多 AI 工具與新的 coding 方法。
9. **問題層級提升**：逐漸從「解決自己的足球分析問題」走向「利用技術解決其他人的學習問題」。

### 3.2 父親／Mentor 的正確角色定位
- **切勿**：把父親寫成替陽甫完成研究、指定成果或編寫程式的人。
- **正確定位**：父親提供的是「真實問題觀察、共同討論、資源支持與長期陪伴」；陽甫本人始終是學習、嘗試、技術實作與解決問題的主體。

### 3.3 A01 與 P02 之 Python 敘事分工
- **正式課程基礎（A01）**：呈現校內 Python 與 Arduino 課程建立了正式學習基礎，APCS 提供外部標準檢測。
- **自主問題驅動（P02）**：當需要處理足球數據等更複雜的真實問題時，則進一步自學爬蟲與資料處理能力，相關延伸歷程收錄於 P02。
- **關係**：兩者為互補的「正式學習基礎」與「真實問題驅動自學」，不自行推定先後順序。

# 4. P02 與足球背景的關鍵定位

### 4.1 P02 的橋樑功能
P02 不只是單純的「足球資料分析專題」，它是整條成長軌跡中最重要的關鍵橋樑：

$$\text{足球興趣} \to \text{真實問題需求} \to \text{原有C++基礎不足} \to \text{自學Python/爬蟲/AI} \to \text{解決問題} \to \text{走向資訊研究探索}$$

- **P02 的核心命題**：「**真正想解決問題時，會主動學會需要的工具。**」

### 4.2 足球成長背景的正確精神
足球歷程跨越幼兒園至高中（安聯小小世界盃 $\to$ 學童盃全國第三 $\to$ 國中甲組校隊隊長 $\to$ 高中全國第五/第六）。  
國中升學時曾認真考慮足球體育班，後選擇普通班。當時家庭討論的共識是：

> **「去歐洲踢球的夢想沒有消失，也可以透過讀書、進入好的大學、未來到歐洲研究所等不同路徑接近。」**

- **核心精神**：「**沒有放棄原本的夢想，而是增加了更多走向世界的可能。**」
- **使用邊界**：幼兒園/國小素材僅在成長軌跡中作為 10 年以上長期生命線的佐證（1~2 個精簡節點），絕不做成童年相簿。

# 5. A01｜校內學習與自主拓展（正式定位與架構）

`A01｜校內學習與自主拓展` 不是「剩餘資料收納頁」，而是補足兩項尚未完整呈現的能力：
1. **穩定的校內學習基礎**
2. **從課堂向外延伸的自主拓展**

- **核心命題**：
  > **「在足球、研究與競賽並行期間，仍維持穩定的校內學習表現，並從正式課程進一步拓展資訊能力、外部檢測與多元參與。」**

### 5.1 預定兩頁分工

#### 第 1 頁｜穩定的校內學習基礎
- **班級排名**：四學期班排維持 **3 $\to$ 3 $\to$ 5 $\to$ 3**（四學期皆維持班級前五）。
- **學科成績**：呈現數理及資訊相關代表成績與優異學業表現。
- **模考佐證**：僅作為小型佐證呈現高二階段（自然組班排 1/34、校排 10/325；社會組班排 1/34、校排 7/325），不放大總級分，亦不以模考作為主敘事。
- **多重任務平行政證**：用足球聯賽跨週複賽與科展繳交時間衝突之真實行程重疊事實，證明高強度並行下課業與競賽的雙重穩定。

#### 第 2 頁｜從課堂延伸到課外
- **資訊正式課程**：校內 Python 與 Arduino 課程表現。
- **外部標準檢測**：APCS（大學程式設計先修檢測）。
- **重要營隊與活動**：參與之重要科學／資訊營隊與講座。
- **幹部與團隊責任**：幹部任期、團隊溝通責任與多元活動參與。
- **少量精選獎項**：少量尚未在其他 PDF 重複呈現、且確實具有證明價值的獎項。
- *註：英文檢定、英文競賽及英文成績主要內容已在 L01 呈現，不在此重複展開。*

# 6. T01 成長軌跡／能力演進導覽設計原則

原本的 `T01_高中兩年成長時間軸.pdf` 現深化重新定位為：

精選 6～8 個真正具備因果連接的關鍵節點，每個節點包含：

$$\text{時間} + \text{關鍵事件} + \text{為什麼開始／遇到什麼問題} + \text{後來長出什麼} + \text{對應佐證資料代碼}$$

- 篇幅重點集中在國中後段至高中，幼兒園/國小僅保留 1~2 個源頭節點。

# 7. 第一頁與每份 PDF 的設計原則

### 7.1 第一頁核心命題原則
第一頁不要直接寫自我貼標籤的句子（如「我是一個有毅力、勇於挑戰的人」）。應提出一個能夠貫穿全冊的「核心命題」，再讓後續資料逐步證明。

**候選核心命題（討論中，尚未定稿）**：
- 「一次結果，從來不是我的終點。」
- 「在每一次結果之後，找出不足，再次挑戰。」

*註：最終第一頁標題應等 6～8 個成長節點完全確定後回頭決定。*

### 7.2 一份 PDF，只證明一句話
每份佐證 PDF 不再是獎狀堆疊，而必須圍繞單一核心命題：

| **`P02 自主學習`** | 遇到真實足球問題時，主動自學所需工具（Python爬蟲/pandas/AI）。 |

# 9. 書審與面試的一致性策略

1. **留白原則**：備審資料不需要把所有細節一次講完，適度留有合理的懸念，讓教授產生好奇，願意在面試中進一步提問。
2. **穩定印象**：整份資料建立的印象不是「這個學生拿很多獎」，而是「這個學生遇到新問題時，會自己找方法、學工具、實作、碰壁、修正，再次往前」。
3. **面試回答對齊**：若面試被問及「優秀申請者眾多，為何選你？」，回答不應強調凌駕他人，而應表達：「我具備穩定的成長機制，進入擁有眾多優秀人才與未知問題的百川環境後，我會持續學習、挑戰與成長。」
