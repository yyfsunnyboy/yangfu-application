## 後續推進工作流程

1. **完成《交大百川手寫自傳｜1000字母版》**
2. **請陽甫先以口語回答自傳訪談題，再整理成陽甫本人的語氣**
3. **由自傳母版發展《交大百川學習計畫｜A4三頁》**
4. **檢查自傳、學習計畫是否與 P01、P02、S01～S04、A01、L01、T01 分工清楚，避免重複堆列獎項**
   - 自傳回答：「陽甫是怎樣的人，以及如何成為現在的自己」
   - 學習計畫回答：「為何選擇百川、入學後要如何學習，以及未來希望完成什麼」
   - 已完成的能力文件是證據，不要在自傳中再次逐項列獎
5. **旺宏決賽結果公布後更新 S03 及所有相關摘要**
6. **最後進行全套檔名、證據代碼、頁數、交叉引用與數字一致性檢查**
7. **百川版本完成後，再改寫清大拾穗、成大不分系等校系版本**
