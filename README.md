葉陽甫｜116學年度特殊選才申請專案（國立陽明交通大學百川學士學位學程為主）

- **段考成績與排名進步**：

  - 114學年度9月學測模擬考：自然組班排 2／35、校排 59／645、總級分 45（國 12、英 13、數A 10、自 10、社 10）

  - *說明：模考母數不同，不可直接宣稱「校排名從59進步到10」而忽略母數差異；記載為「在不同母數的兩次模考中，第二次取得自然組 1／34、校排 10／325」。*
