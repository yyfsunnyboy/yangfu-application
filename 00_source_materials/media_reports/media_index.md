## 手動儲存步驟

1. **方式一：使用瀏覽器列印功能**
   - 開啟原始網址
   - 使用 Ctrl+P 或「列印」功能
   - 選擇「另存為 PDF」
   - 依表格中的檔名儲存

2. **方式二：使用瀏覽器儲存完整網頁**
   - 開啟原始網址
   - 按 Ctrl+S 儲存完整網頁
   - 轉換為 PDF（如使用 Microsoft Print to PDF）
   - 依表格中的檔名重新命名

3. **儲存位置**
   - 所有 PDF 檔案應儲存至：`00_source_materials/media_reports/`
