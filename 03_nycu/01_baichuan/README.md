# 國立陽明交通大學 百川學士學位學程 工作區

> **學程核心定位**：
> 百川學士學位學程為陽甫特殊選才之首要志願與核心母案。其核心敘事為：
> **「爸爸從高職數學教室提出問題，陽甫與團隊把問題帶進 AI 研究與競賽，再把經過驗證與修正的系統帶回原來的教室；百川要承接的，就是這項尚未完成的跨域工作。」**

---

## 一、百川申請的核心邏輯（不改為單一學系模板）

1. **跨領域（Interdisciplinary）**：串連「資訊科學（系統實作與 AST 修復）」、「認知與教育科學（高職數學適性化教學）」與「人機互動現場」。
2. **自主規劃（Self-Directed Learning）**：以未解之 8 項跨域研究課題為導向，自主規劃結合交大資訊、學習科學與跨域學術資源的修課藍圖。
3. **長期專題（Long-term Project）**：自適應學習系統非短暫參賽作品，而是貫穿國中發明、高中競賽、旺宏深化的演進歷程。
4. **資訊 × 教育 × 實際場域（Real-world Grounding）**：走出實驗室，將系統實際部署於花蓮高商課堂進行試用與教師端培訓。
5. **大學資源支撐未完成計畫（Unfinished Agenda）**：誠實指出高中階段技術與場域邊界，以大學高等教育資源作為延續研發之必要支撐。
