# 陽明交通大學特殊選才 00_shared 共用工作區

> **目錄定位**：本資料夾為國立陽明交通大學特殊選才各申請方向（百川學士學位學程、資訊工程學系、電機工程學系）之**跨系共用資料與策略中樞**。

---

## 一、目錄用途與原則

1. **單一事實來源與集中管理**：
   - 這裡保存 NYCU 特殊選才各申請方向共用的招生規定、簡章時程、資格檢核、客觀證據庫、推薦信策略與來源索引。
   - 各系（01_baichuan、02_cs、03_ee）依據此共用基礎展開獨立敘事，避免資訊碎片化或數據不一致。
2. **共用證據，獨立敘事**：
   - 本目錄僅提供客觀事實與索引，各系申請文件必須根據各學程/學系之選才精神獨立撰寫，嚴禁跨系直接複製貼上。
3. **路徑引用，避免檔案冗餘**：
   - 原始獎狀、成績單、專題檔案與影音檔案維持存放在 repo 根層（`00_source_materials/`、`01_master_profile/`、`02_research_project/`）。
   - 本目錄透過 `source_map.md` 建立引用對照，不複製實體 PDF。

---

## 二、檔案架構與功能

- [admissions_requirements.md](file:///d:/Python/yangfu-application/03_nycu/00_shared/admissions_requirements.md)：NYCU 特殊選才共同規定、各系資格、指定文件、甄試方式、推薦函與時程。
- [evidence_inventory.md](file:///d:/Python/yangfu-application/03_nycu/00_shared/evidence_inventory.md)：NYCU 三個申請方向共用之客觀證據分類與能力證明清單。
- [recommendation_strategy.md](file:///d:/Python/yangfu-application/03_nycu/00_shared/recommendation_strategy.md)：推薦人人選規劃、證明能力維度、適用系所與防重疊策略。
- [source_map.md](file:///d:/Python/yangfu-application/03_nycu/00_shared/source_map.md)：記錄 NYCU 各系備審對應至 repo 原始檔案的引用關係與版本原則。
