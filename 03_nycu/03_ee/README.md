# 申請目標

國立陽明交通大學 電機工程學系 特殊選才（115/116學年度）

---

# 核心定位

**「從端到端 AI 資訊系統建構與 Arduino 實體控制迴路的整合經驗出發，深刻理解純軟體演算法無法獨立於底層晶片、微處理機架構與訊號傳輸而存在；渴望進入半導體與電子工程核心殿堂之陽明交大電機系，探索智慧計算背後的硬體實現、嵌入式系統與系統工程本質。」**

---

# 審查者應該在 30 秒內理解的三件事

1. **具備工程實作與問題拆解本能**：國中即具備硬體接線與感測控制經驗（IEYI 銀獎），高中於「Arduino 程式設計」獲 94 分並獨立完成節能防呆警報器，具備將邏輯化為具體電路控制之能力。
2. **具備大型複雜系統的整合與容錯工程思維**：在自適應學習系統研發中負責系統整合，面對錯誤能提出 AST 確定性修復與棄權機制，展現追求高可靠度（High Reliability）的工程師素養。
3. **動機明確且深知軟硬體協同（HW/SW Co-design）之重要性**：不盲目跨域，而是看見未來 AI 算力與智慧應用的瓶頸在於硬體底層，渴望在交大電機接受正統工程學門訓練。

# 文件結構

- `T00_profile/`：一頁式電機申請人總覽（工程技能、實作作品、數理底盤）。
- `T01_autobiography/`：自傳（從動手做創客到面對複雜工程系統之軌跡）。
- `T02_why_ee/`：申請動機（為何選擇交大電機？AI 系統背後的硬體與工程召喚）。
- `T03_research_and_system/`：專題與系統架構（自適應系統之狀態機與資料流控制）。
- `T04_engineering_thinking/`：工程思維與除錯（從感測迴路到確定性修復之容錯工程觀）。
- `T05_external_validation/`：外部競賽驗證（IEYI 銀獎、育秀盃金獎、旺宏 20 強）。
- `T06_study_plan/`：學習計畫（電路學、電子學、電磁學、微處理機、訊號與系統之修課藍圖）。
- `T07_supporting_evidence/`：佐證資料彙編（成績單、Arduino 課業成果、英文、體育表現）。
- `final/`：最終送件版 PDF 與輸出文件。
