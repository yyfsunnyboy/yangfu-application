# Questions Reviewers May Ask

1. **為什麼陽甫適合電機，而不只是資工？**
   - *待辦核心問題*：如何清楚闡述「想碰觸實體世界、想理解計算背後的硬體電路與訊號，而不滿足於純粹軟體抽象」之真實轉變？
2. **AI 系統經驗與電機領域真正的連結是什麼？**
   - *待辦核心問題*：自適應系統的軟體架構，如何與電機領域的「系統工程（System Engineering）」、「狀態機（State Machine）」與「回授控制（Feedback Control）」產生本質連結？
3. **哪些現有證據能證明工程能力？**
   - *待辦核心問題*：IEYI 遮雨棚、高中 Arduino 警報器，以及 AST Healer 的確定性修復邊界，各自在工程維度上的說服力在哪？
4. **哪些地方目前仍不足，不能過度包裝？**
   - *待辦核心問題*：切忌將高中 Arduino 習作成品過度吹捧為「深層嵌入式系統研發」，切忌聲稱精通電路設計或半導體物理。
5. **清大電機與清大資工版本應如何區隔？**
   - *待辦核心問題*：兩系審查教授背景截然不同，資工著重演算法與軟體架構，電機著重工程實現、系統控制與物理實現，敘事語言如何徹底分流？
