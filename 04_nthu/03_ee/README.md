# 申請目標

國立清華大學 電機工程學系 特殊選才（115/116學年度）

---

# 核心定位

**「從完整資訊與 AI 系統的建構經驗出發，深刻體認到軟體演算法無法脫離底層硬體架構、訊號傳輸與工程控制而獨立存在；希望從系統工程思維跨入電機領域，理解支撐現代智慧運算背後更完整的計算硬體、嵌入式控制、通訊與工程基礎。」**

---

# 審查者應該在 30 秒內理解的三件事

1. **具備工程實作與問題拆解本能**：國中即具備感測控制與硬體接線經驗（智慧遮雨棚 IEYI 銀獎），高中則進一步自主完成 Arduino 智慧節能防呆警報器，能將抽象邏輯落地為具體實體控制迴路。
2. **具備大型複雜系統的整合與除錯經驗**：在 AI 自適應學習系統研發中，負責資料流整合、狀態機維護與軟體介面契約，具備跨模組整合與容錯工程思維（Fault-Tolerant Engineering）。
3. **動機明確且不盲目跨域**：並非將電機當作備胎，而是深刻體認到高階智慧系統（如 edge AI、硬體加速、感測控制）的瓶頸往往在於軟硬體界面，渴望在清大電機接受嚴謹的工程科學訓練。

# 與其他申請版本的差異

- **對比清大資工 (01_cs)**：
  - 電機版不聚焦在「純純編譯理論或純軟體架構」，而是將重點轉移至**「工程實現（Engineering Implementation）」、「系統控制（System & Control）」、「軟硬體介面（HW/SW Co-design）」與「底層運算平台」**。
- **對比清華學院學士班（IPTH） (04_nthu/03_ipth)**：
  - 電機版鎖定嚴格的**工程學門（Engineering Disciplines）**，不強調社會實踐或教育科技政策，而是探討技術本身的可靠度與工程實現。
- **對比交大百川 (03_nycu/01_baichuan)**：
  - 百川為不分系跨域學程，電機版則是傳統硬核工程學院，必須展現出對物理、電路、訊號與系統工程的敬畏與扎實學習決心。

# 文件結構

- `T00_profile/`：一頁式電機申請人總覽（工程實作、專案整合、數理底盤）。
- `T01_autobiography/`：自傳（從動手做創客到面對複雜系統的工程探索史）。
- `T02_why_ee/`：申請動機（為何選擇電機？AI 系統背後的底層硬體與通訊呼喚？）。
- `T03_research_and_system/`：專題與系統架構（自適應學習系統之模組化架構與資料整合）。
- `T04_engineering_thinking/`：工程思維與除錯（從 Arduino 實體控制到 AST 確定性修復之容錯工程觀）。
- `T05_external_validation/`：競賽與外部驗證（育秀盃金獎、IEYI 銀獎、旺宏 20 強）。
- `T06_study_plan/`：學習計畫（電路學、電子學、訊號與系統、微處理機系統、計算機組織）。
- `T07_supporting_evidence/`：佐證資料（成績單、Arduino 課業成果、英文檢定、體育表現）。
- `final/`：最終送件版 PDF 與輸出文件。
