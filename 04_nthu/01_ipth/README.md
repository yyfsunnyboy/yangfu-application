# 核心定位

**「我選擇清華學院學士班（IPTH），不是因為對未來迷惘或尚未決定方向，而是因為手頭上已經有一個真實跨越『資訊工程、認知教育與地方教學場域』的持續型專案；我需要清華學院學士班的跨領域修課彈性與學術自主性，結合個人長期深耕的資訊研發、競技體育自律與外語溝通三條能力線，把這個真正改變高職教育痛點的專案徹底做深、做大、做實。」**

---

# 審查者應該在 30 秒內理解的三件事

1. **具備清楚且正在運行的跨域實踐主題**：陽甫不是「什麼都想碰一點」，而是帶著已經獲獎（育秀盃金獎、神通冠軍、旺宏 20 強）並正在花蓮高商試用導入的 AI 自適應學習系統，尋求清華學院學士班（IPTH）跨域資源支持。
2. **具備罕見的三條長期並行能力線**：
   - **資訊／研究**：AST Healer、系統整合、科展挫折與旺宏 20 強。
   - **運動競技**：十餘年足球訓練、校隊隊長與全國五人制聯賽全國前六，培育極高抗壓性與團隊協作。
   - **外語素養**：全民英檢中高級通過、英文演講第一名，具備無障礙吸收全球知識與對外溝通能力。
3. **具備高度自主規劃與執行力**：在課業、球隊高強度訓練與多項專案多線並行下，高中四學期穩定維持班排前五，證明擁有駕馭清華學院學士班高度自主修課所需的自律與時間管理能力。

# 與其他申請版本的差異

- **對比清大資工 (01_cs)**：
  - 資工版聚焦於純粹的「演算法、編譯器、作業系統與軟體可靠度」；IPTH 版則將技術視為解決問題的槓桿，敘事重心轉移至**「資訊科技如何跨入教育科學、使用者介面、地方教育場域與社會實踐」**。
- **對比清大電機 (02_ee)**：
  - 電機版鎖定正統硬核工程學門與底層計算硬體；IPTH 版強調**「文武兼備、跨界整合與解決複雜真實社會問題的綜合領導力」**。
- **對比交大百川 (03_nycu/01_baichuan)**：
  - 百川版本著重於「百川學士學位學程」之特殊選才脈絡；清華學院版本則緊扣**清華「拾穗計畫」尋求特殊專才、跨域領袖與社會關懷之精神**重新定制。

# 文件結構

- `T00_profile/`：一頁式綜合申請人總覽（跨域畫像、三線並行亮點、學業數據）。
- `T01_autobiography/`：自傳（文武兼備的成長軌跡、球場上的挫折與教育專案的起點）。
- `T02_multidisciplinary_profile/`：跨領域特質描繪（為何選擇清華學院學士班？如何拒絕平庸的雜而不精？）。
- `T03_research_and_cs/`：資訊研究與系統實作（自適應學習系統、AST Healer 與外部驗證）。
- `T04_sports/`：體育競技歷程（十年足球、全國賽前六、抗壓性與自律證明）。
- `T05_english/`：語言能力與跨文化素養（GEPT 中高級、演講、原典研讀與國際交流）。
- `T06_future_project/`：持續推進之教育科技專案（花蓮高商導入經驗與清華階段專題藍圖）。
- `T07_study_plan/`：學習計畫（清華學院修課自主規劃：資工 + 學習科學/教育 + 社會實踐）。
- `T08_supporting_evidence/`：完整佐證文件彙編（獎狀、成績單、檢定、出賽紀錄）。
- `final/`：最終送件版 PDF 與輸出文件。
