# 清華大學特殊選才 00_shared 共用工作區

> **目錄定位**：本資料夾為國立清華大學特殊選才三個申請方向（資訊工程學系、電機工程學系、清華學院學士班（IPTH））的**跨系共用資料庫**。

---

## 一、目錄用途與原則

1. **單一事實來源 (Single Source of Truth)**：
   - 清大共同報考規定、時程、資格檢核、推薦信策略與全案證據索引集中於本處維護。
   - 避免各系重複建立碎片化文件或導致資訊不一致。
2. **共用不等於文字複製**：
   - 本目錄僅提供**原始事實基礎、簡章規定與證據索引**。
   - 各系（01_cs、02_ee、03_ipth）必須依據各自的學系特性與定位重新敘事，嚴格禁止跨系直接複製貼上文章。
3. **無實體檔案重複**：
   - 原始證書、成績單、論文報告與影音檔案維持存放在 repo 頂層共用區（`00_source_materials/`、`01_master_profile/`、`02_research_project/`）。
   - 本目錄透過 `source_map.md` 建立引用路徑，不複製實體 PDF。

---

## 二、檔案清單與功能

- [admissions_requirements.md](file:///d:/Python/yangfu-application/04_nthu/00_shared/admissions_requirements.md)：清大特殊選才共同規定、各系資格、指定繳交文件、甄試比例與時程。
- [evidence_inventory.md](file:///d:/Python/yangfu-application/04_nthu/00_shared/evidence_inventory.md)：清大三個系所共用之客觀證據分類與可證明邊界清單。
- [recommendation_strategy.md](file:///d:/Python/yangfu-application/04_nthu/00_shared/recommendation_strategy.md)：推薦信人選規劃、推薦重點分配與防重疊策略。
- [source_map.md](file:///d:/Python/yangfu-application/04_nthu/00_shared/source_map.md)：清大申請資料對應至 repo 既有檔案的來源對照與引用關係。
