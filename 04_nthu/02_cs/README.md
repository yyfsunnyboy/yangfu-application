# 申請目標

國立清華大學 資訊工程學系 特殊選才（115/116學年度）

---

# 核心定位

**「不是因為喜歡 AI 的表層應用而想讀資工，而是在真正建構、除錯並落地 AI 教學系統的過程中，遭遇了程式可靠性、抽象語法樹解析、系統架構、資料流處理與軟體工程邊界問題，進而發現真正吸引自己並渴望深造的，是資訊工程（Computer Science）本身。」**

---

# 審查者應該在 30 秒內理解的三件事

1. **具備真實系統建構與整合能力**：非停留在 prompt 呼叫或空談構想，而是獨立承擔 AI 自適應學習系統之資料主線、狀態管理、作答介面與多模組整合，並具備高職課堂試用部署經驗。
2. **具備科學探究與系統可靠度意識**：面對 LLM 程式生成錯誤，能深入研究 AST 確定性修復與棄權機制（Abstention），並從東區科展挫折中徹底檢討實驗設計與基準測試，入圍旺宏科學獎全國決賽 20 強。
3. **具備自律底盤與強烈補足 CS 核心理論的動機**：在多項競賽與研究高壓下維持班排前五，清晰認知自身在演算法、計算機系統、作業系統等底層理論的不足，帶著真實問題意識進入清大資工深化學習。

# 與其他申請版本的差異

- **對比清華電機 (02_ee)**：
  - 資工版聚焦於**軟體架構、程式語言與語法樹（AST）、資料流程、演算法邊界、系統可靠度與測試驗證**；電機版則著重在軟硬體介面、感測控制與底層計算硬體。
- **對比清華學院學士班（IPTH） (04_nthu/03_ipth)**：
  - 資工版以**電腦科學理論與軟體工程實踐為絕對主軸**，足球與英文僅作為證明自律管理與閱讀文獻的輔助證據；不分系版則將「資訊、體育、外語」三線作為多元特質並重，並以教育科技社會實踐為主軸。
- **對比交大百川 (03_nycu/01_baichuan)**：
  - 資工版徹底重構敘事，完全屏除不分系跨領域選才包裝，直接針對資工教授最在意的**程式設計扎實度、演算法理解深度、架構設計思維與軟體工程規範**展開。

# 文件結構

- `T00_profile/`：一頁式申請人總覽（個人亮點、關鍵數據、能力雷達）。
- `T01_autobiography/`：自傳（個人成長歷程與如何一步步走向資訊工程）。
- `T02_why_cs/`：申請動機（為何是資工？為何不停留在應用？經驗如何與 CS 核心連結？）。
- `T03_technical_core/`：技術核心頁（AST Healer 確定性修復、棄權機制、基準測試與實驗重構）。
- `T04_system_engineering/`：系統工程頁（AI 學習系統全端架構、資料主線、教師端/學生端、實際課堂部署）。
- `T05_external_validation/`：外部驗證與反思歷程（東區科展挫折修正、旺宏決賽、育秀盃金獎、神通冠軍）。
- `T06_study_plan/`：讀書計畫（針對演算法、計算機系統、OS、網路、軟體工程之修課規劃與研究展望）。
- `T07_supporting_evidence/`：輔助佐證（在校成績單、APCS、英檢、足球隊自律佐證）。
- `final/`：最終送件版 PDF 與輸出文件。
