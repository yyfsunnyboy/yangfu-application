國中時我和兩位同學製作「多功能智慧遮雨棚」，獲 2023 IEYI 臺灣選拔賽銀獎。我負責 Arduino 接線、程式、App Inventor 軟體與手機控制。感測器偵測雨滴、溫溼度與距離，判斷後控制馬達收放遮雨棚。只要一條線接錯，系統就毫無反應。這讓我體會程式必須與實體環境協同運作才算完成。

當系統能運作之後，我開始追問怎麼證明它
系統獲 2026 扶輪盃全國高中組第一名與第 23 屆育秀盃金獎。隨題型增加，依賴雲端大模型帶來昂貴 API 成本與延遲。我嘗試改用本地小模型，實測卻發現程式生成極不穩定。我轉而思考：如何讓小模型減少負擔，卻能產出穩定的程式。
我觀察到同單元程式結構與錯誤具規律性，採取兩項策略：生成前以 Scaffolding 與 Domain Functions 提供規範，降低規劃負擔；生成後以 AST Active Healer 針對確定規則修復局部錯誤，無法定奪則不介入。初版實驗中，自建指標 MCRI 取得 97.41 分，當時誤以為已證明有效。
本研究獲東區科展優等，並入圍第 25 屆旺宏科學獎全國 20 強（846件）。評審指正實驗衡量需加強並聚焦 Healer。我重構正式實驗：嚴格隔離測試集、凍結規則並逐筆追蹤失敗，實測安全救援率為 2.63%。分析發現約四成屬算法與數學邏輯錯誤，本非語法修復範圍。

從 AI 軟體系統，走向我還不理解的運算平台
雲端大型模型→ 本地小模型→ 運算位置與資源→ Edge AI／嵌入式系統→ 軟硬體整合
實測小模型使我深入思索運算分工：何種任務留雲端、何者入邊緣？處理器與記憶體又如何制約效能？這引導我關注 Edge AI 與嵌入式系統。

我尚未接觸裝置端 Edge AI 部署、FPGA/NPU 晶片設計，亦缺乏處理器結構與數位電路之系統化知識。
我目前已有
Python · AI 系統開發· 模型串接
系統整合· 程式可靠度研究· 實驗驗證
下一步需要補足
電路· 數位邏輯· 微處理機
計算機結構· 嵌入式系統· 軟硬體整合
做遮雨棚能接線寫程式，卻未諳電路原理；測小模型能計延遲，卻不知底層硬體制約。成大電機的電路學、電子實驗與邏輯系統能補足硬體根基；計算機組織與作業系統則助我透析程式與模型如何調度處理器與記憶體。我期盼將所學回饋已運行的 AI 系統，由純軟體逐步邁向雲邊端軟硬整合。

成大極重視運動精神，足球校隊征戰大專聯賽（UFA）最高殿堂：男生組公開第一級（公開一級），是我極嚮往成大的關鍵動機。我長期任花中主力（背號 42），獲 114 學年度全國五人制第五名、113 學年度第六名，連兩年挺進全國 8 強（具運績資格）。高強度競技淬鍊出抗壓韌性與團隊紀律，是我投入科研工程的心理基石；入學後我渴望入隊征戰公開一級、為校爭光。
