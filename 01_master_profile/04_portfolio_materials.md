| 素材名稱 | 對應文件／代碼 | 採用理由 | 潛在風險與防範措施 |
| :--- | :--- | :--- | :--- |
| **自適應學習系統研發歷程** | `S01`、`S02`、`S04`、`S03` | 1. 貫穿高中兩年的核心研究專案。<br>2. 展現從教師痛點轉譯、資料主線實作（S01）、多模組系統整合（S02）、科展反思修正（S04）到 Healer 邊界與棄權實驗（S03）的完整科研閉環。<br>3. 獲神通冠軍、育秀盃金獎、東區科展優等及旺宏全國 20 強高度肯定。 | **風險**：被誤認為四個獨立作品或誇大個人獨立完成。<br>**防範**：明確定位為同一套系統在不同階段之演化；清晰界定三人團隊分工（陽甫：Prompt/Healer+系統整合；蔡昕諾：PPO；林昕佑：Hybrid RAG）；旺宏標註「待決賽結果後更新，不得預寫獲獎」。 |

| **足球競技與運動歷程** | `P01` | 1. 展現長期紀律、普通班克服訓練落差的自律心志（長期投入）。<br>2. 證明高壓決策、團隊信任與面對輸球後回去加強的修正韌性。<br>3. 全國聯賽連兩年殺入前 5/6 強（擊敗惠文高中）。 | **風險**：被誤解為單純體育成績或流水帳照片。<br>**防範**：將體育經驗與科研態度進行深層精神對接，聚焦於性格底色的形成。 |

## 3. 系所版本策略 (Department Adaptation Strategy)

根據不同大學校系之審查重點，調整素材排序與側重點：

### 3.1 資訊工程／資工系 (CS)
- **重點強調**：
  - Programming, Algorithms, Data Structures
  - Software Engineering & System Integration（S02 多模組整合、S01 資料主線）
  - Reliable AI, Testing, Validation & Debugging（S03 Healer 邊界實驗、棄權機制、Pass/Fail 基準測試）
  - Version Control, Team Collaboration（三人團隊分工）
  - APCS 觀念 5 級客觀檢驗與自我提升計畫

### 3.2 電機工程／電子系 (EE)
- **增加強調**：
  - Arduino, Sensors, Embedded Systems（A02 智慧節能防呆警報器、國中遮雨棚）
  - Hardware / Software Integration（App Inventor + Arduino、感測器讀取與致動器控制）
  - Control Logic, Input-Process-Output 閉環
  - System Debugging & Minimal Test（最小化測試與循序除錯）

### 3.3 陽明交大百川學士學位學程／不分系 (Baichuan / Interdisciplinary)
- **核心敘事**：
  - 教育問題 $\to$ 數學教學需求 $\to$ 程式實作 $\to$ AI 系統 $\to$ 自適應學習架構 $\to$ 科學研究驗證 $\to$ 重新回到課堂試用
  - 足球（體育紀律與抗挫）、英文（國際溝通與原典研讀）、硬體實作（動手問題拆解）所交織出的跨域個人發展路徑
  - 帶著高中執行兩年之真實未解課題進場，對接百川跨域修課藍圖
